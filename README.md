# OLETUS

**고딕 저택에서 1 대 1로 맞붙는 3D 대전 액션 게임**

생존자와 감시자 중 한 편을 골라 싸웁니다. **상대 체력을 먼저 0으로 만들면 이깁니다.**

---

## 시작하기

1. **타이틀 화면**
   - `게임 시작`: 캐릭터 선택으로 넘어갑니다.
   - `옵션`: 음량을 바꿉니다.
   - `크레딧`, `게임 종료`
2. **캐릭터 선택**
   - `W` / `S`: 감시자 ↔ 생존자
   - `A` / `D`: 캐릭터 넘기기
   - 캐릭터 정보 칸의 조작 설명에 마우스를 올리면 자세한 설명이 나옵니다.
   - `ESC`: 타이틀로 돌아가기
3. **모드 고르기**

| 모드 | 키 | 설명 |
|---|---|---|
| **연습** | `1` · `Space` · `Enter` | 움직이지 않는 훈련 상대와 연습합니다. 스킬 쿨타임이 없고 체력도 줄지 않습니다. `ESC`로 나갑니다. |
| **대전** | `2` · `G` | 반대편 캐릭터 중 하나가 무작위로 AI 상대가 됩니다. 승패가 나면 `R`을 눌러 캐릭터 선택으로 돌아갑니다. |

---

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 (카메라가 보는 방향 기준) |
| 마우스 **오른쪽 버튼을 누른 채** 움직이기 | 시점 돌리기 |
| `Shift` (이동 중) | 달리기 (노란 스태미나 바를 씁니다) |
| `Space` | 점프 · 창틀 넘기 · 턱 오르기 |
| 왼쪽 클릭 **짧게** | 평타 |
| 왼쪽 클릭 **꾹** | 감시자: 모아 치기 · 생존자: 막기(패링), 떼면 돌려차기 |
| `E` | 캐릭터 고유 스킬 |
| 달리면서 점프 → 공중에서 왼쪽 클릭 | 생존자: 발차기 · 감시자: 내려치기 |

- 창틀·사다리·턱 매달리기는 그쪽으로 이동 키를 누르면 저절로 됩니다.
- 턱에 매달렸을 때: `W` 올라가기 · `A` / `D` 옆으로 · `S` 손 놓기
- **생존자 전용:** 판자 근처에서 `Space`를 누르면 점프 대신 판자를 내립니다.

## 생존자와 감시자

| | 생존자 | 감시자 |
|---|---|---|
| 체력 | 100 | **150** |
| 평타 | 피해는 작지만 상대를 **멈추게 하고 멀리 밀어냅니다** | **한 방이 큽니다.** 서너 대면 생존자가 쓰러집니다 |
| 달리기 | 빠르고 오래 달립니다 | 걷기는 빠르지만 오래 달리지 못합니다 |
| 특기 | 막기(패링), 벽꿍, 판자 | 큰 한 방, 원거리·돌진 스킬 |

### 생존자로 이기는 법
- **막기:** 왼쪽 클릭을 꾹 누르고 있으면 정면에서 오는 공격을 막습니다. 막히면 감시자가 잠깐 굳으니 그때 반격하세요.
- **벽꿍:** 평타로 밀려난 상대가 벽에 부딪히면 큰 피해를 입습니다. **달리며 점프 발차기**로 벽 쪽으로 차 넣는 것이 기본입니다.
- **두 번째 발차기:** 발차기 뒤 공중에서 한 번 더 클릭하면 한 번 더 찹니다. 머리에 맞히면 상대가 넘어집니다.
- **떨어뜨리기:** 높은 곳(3층 우물, 무너진 곳, 옥상 길)에서 밀어 떨어뜨리면 큰 피해가 들어갑니다.
- **판자:** 문간이나 좁은 틈의 판자를 내려 감시자를 깔면 큰 피해를 주고 기절시킵니다. 판자는 한 번만 쓸 수 있습니다.

### 감시자로 이기는 법
- 한 방이 크지만 느리고, 빗나가면 빈틈이 큽니다. **확실할 때만 휘두르세요.**
- 생존자가 막고 있으면 **옆이나 뒤로 돌아가서** 치세요. 뒤에서 치면 더 아픕니다.
- **창틀을 넘는 중인 상대는 피해를 2배로** 받습니다.
- 달리기가 짧으니 스태미나를 아껴 두세요.

## 캐릭터

### 생존자

| 캐릭터 | 스킬 (E) | 이렇게 씁니다 |
|---|---|---|
| 의사 | 자가치료 | 1.5초 동안 제자리에서 주사를 놓아 체력 40%를 회복합니다. 도중에 끊기면 회복되지 않습니다 |
| 포워드 | 럭비공 돌진 | 돌진해 부딪힌 상대를 밀어냅니다. 오래 달릴수록 멀리 밀고, 벽까지 밀어붙이면 오래 기절합니다 |
| 용병 | 아대 | 켜 두면 벽에 닿을 때마다 벽을 차고 원하는 방향으로 초고속 도약합니다 |
| 공군 | 신호총 | 가장 가까운 상대를 따라가는 신호탄을 쏩니다. 맞으면 기절합니다 |
| 카우보이 | 올가미 | 올가미로 상대를 잡아 뛰어넘으며 피해를 주고, 잠깐 빨라집니다 |
| 맹인 | 지팡이 | 왼쪽 클릭을 누른 채 좌우로 그어 후려 밀고, E로 앞으로 찔러 밀어냅니다. 벽에 박힌 상대는 잠시 평타를 못 씁니다 |
| 도둑 | 손전등 | 빛을 비추면 상대의 E를 잠그고, 얼굴에 오래 비추면 기절시킵니다 |

### 감시자

| 캐릭터 | 스킬 | 이렇게 씁니다 |
|---|---|---|
| 사냥터지기 | 그랩 | E를 누른 채 겨누고 떼면 그랩을 던져 상대를 끌어옵니다. 벽에 먼저 걸리면 내가 날아갑니다 |
| 재앙의 도마뱀 | 도약 내려찍기 | 높이 뛰어올라 공중에서 클릭하면 착지 지점 둘레를 내려찍습니다 |
| 리퍼 | 안개 칼날 | 안개가 2칸 차면 평타와 함께 넓은 칼날이 날아갑니다. E는 1칸으로 작은 칼날을 날립니다. 칼날이 지나간 안개 위에서는 빨라집니다 |
| 붉은나비 | 나비 비행 | 왼쪽 클릭을 꾹 눌러 멀리 나비를 놓고, E로 그 나비에게 날아갑니다. 나는 동안은 맞지 않습니다 |
| 광대 | 로켓 돌진 | E를 꾹 눌러 로켓을 들고 걷다 떼면 돌진합니다. 오래 달릴수록 상대가 길게 기절합니다 |
| 안토니오 | 음표 | 음표 두 개를 5초 안에 놓으면 전류선이 이어지며 선 위의 상대를 칩니다 |
| 공장장 | 인형 · 분신 | 인형을 던지고 E로 자리를 바꿉니다. E를 꾹 누르면 상대를 끝까지 쫓는 분신을 부릅니다 |
| 노란옷의 왕 | 촉수 | 땅에 촉수를 세우고, E로 골라 부채꼴로 내려찍습니다. 밑동 가까이는 안전합니다 |

캐릭터 선택 화면에서 각 캐릭터의 조작 설명에 마우스를 올리면 더 자세히 볼 수 있습니다.

## 맵: 고딕 저택

본관(3층)·서관·동관이 안뜰을 둘러싸고, 바깥에는 묘지와 판자 구역이 있습니다.

| 볼거리 | 설명 |
|---|---|
| 창틀 | 넘어서 지름길로 갈 수 있습니다. 넘는 동안 맞으면 피해가 2배입니다 |
| 판자 (생존자만) | 문간·좁은 틈에 있습니다. 내려서 감시자를 깔 수 있고, 한 번만 쓸 수 있습니다 |
| 순간이동 거울 | 맵 네 모서리에 있고 **대각선끼리** 이어집니다. 걸어 들어가면 반대편 모서리로 나옵니다. 누구나 쓸 수 있고, 쓴 뒤 잠시 다시 못 씁니다 |
| 사다리 | 동관과 서관에 있습니다. 오르는 동안 스태미나가 줄고, 다 떨어지면 미끄러집니다 |
| 높은 곳 | 3층 우물, 무너진 곳, 옥상 길, 옥상 테라스에서 떨어지면 큰 피해를 입습니다 |
| 본관 지붕 | **햇볕에 탑니다.** 오래 서 있지 마세요 |

## 처음 하는 분을 위한 팁

1. **연습 모드부터** 해 보세요. 쿨타임이 없어 스킬을 마음껏 써 볼 수 있습니다.
2. 생존자라면 **왼쪽 클릭을 꾹 누르는 습관**을 들이세요. 막기에 성공하면 반격 기회가 생깁니다.
3. 생존자의 큰 피해는 **벽꿍과 떨어뜨리기**에서 나옵니다. 상대를 벽이나 낭떠러지 쪽으로 몰아가세요.
4. 감시자는 **서두르지 마세요.** 빗나가면 그만큼 맞습니다.
5. **점프로 평타를 피할 수 있습니다.** 땅에서 휘두르는 공격은 높이 뛴 상대에게 닿지 않습니다.
6. 스태미나가 바닥나면 한동안 걷기만 할 수 있습니다. **노란 바를 보며 달리세요.**
7. 멀리 가야 할 때는 **모서리 거울**로 반대편 모서리까지 한 번에 가세요.
