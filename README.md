# OLETUS

**제5인격(Identity V) 캐릭터들이 고딕 저택에서 1 대 1로 맞붙는 3D 격투 게임**입니다.

> OLETUS는 **비영리 팬 게임**이며 어떤 형태의 수익도 내지 않습니다.
> Identity V와 관련 캐릭터·이름·에셋의 권리는 각 권리자에게 있습니다. 이 프로젝트는 권리자와 관계가 없고, 권리자의 승인을 받지 않았습니다.

원작 게임을 몰라도 괜찮습니다. 원작 규칙(해독기, 탈출, 의자)은 없습니다. **상대 체력을 0으로 만들면 이기는 대전 게임**입니다.

- 규칙과 숫자를 모두 보려면 → **[게임 룰북 (Docs/GameRules.md)](Docs/GameRules.md)**

---

## 한 판은 이렇게 흘러갑니다

1. **타이틀**에서 `Start Game`을 누릅니다. `Options`에서 음량을 바꿀 수 있습니다.
2. **캐릭터 선택**에서 편과 캐릭터를 고릅니다.
   - `W` / `S`로 감시자와 생존자 사이를 오가고, `A` / `D`로 캐릭터를 바꿉니다.
3. 모드를 고릅니다.
   - `1` (또는 `Space`, `Enter`): **연습 모드**
     - 움직이지 않는 훈련 상대가 있고, 스킬 쿨타임이 없습니다. 공격에 맞아도 체력이 줄지 않습니다.
     - `ESC`로 나갑니다.
   - `2` (또는 `G`): **AI 대전**
     - 반대편 캐릭터 중 하나가 무작위로 AI 상대가 됩니다.
     - **먼저 체력이 0이 되는 쪽이 집니다.**
     - 끝나면 `R`을 눌러 캐릭터 선택으로 돌아갑니다.

---

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 (카메라가 보는 방향 기준) |
| `Shift` (이동 중) | 달리기. 아래 노란 바(스태미나)를 씁니다 |
| `Space` | 점프 · 창틀 넘기 · 턱 오르기 · (생존자) 판자 내리기 |
| 마우스 **오른쪽 버튼을 누른 채** 움직이기 | 시점 돌리기 |
| 왼쪽 클릭 **짧게** | 평타 |
| 왼쪽 클릭 **길게** | 감시자: 모아 치기 · 생존자: 막기(패링), 떼면 돌려차기 |
| `E` | 캐릭터 고유 스킬 |
| 앞으로 달리다 `Space` → 공중에서 왼쪽 클릭 | 달리기 점프 공격 |

- 창틀, 사다리, 턱 매달리기는 해당 방향으로 키를 누르면 저절로 됩니다.
- 매달린 상태에서는 `W` 올라가기, `A` / `D` 옆으로 이동, `S` 손 놓기입니다.

## 생존자와 감시자

같은 격투 게임이지만 두 편은 싸우는 방식이 완전히 다릅니다.

| | 생존자 | 감시자 |
|---|---|---|
| 체력 | 100 | **150** |
| 평타 | 피해는 아주 작습니다(3~5). 대신 상대를 **멈추게 하고 멀리 밀어냅니다** | **한 방이 큽니다**(30~54). 생존자를 3~4대면 쓰러뜨립니다 |
| 달리기 | 빠르고(6.8 m/s) 오래 달립니다(약 10초) | 걷기가 빠르지만(4.6 m/s) 달리기는 짧습니다(약 5초) |
| 특기 | 막기(패링), 벽꿍, 판자 | 큰 한 방, 원거리 설치·돌진 스킬 |

### 생존자는 이렇게 이깁니다
- **막기(패링):** 왼쪽 클릭을 누르고 있으면 정면에서 오는 감시자 평타를 막습니다. 막히면 감시자가 0.5초 동안 굳습니다. 그 틈에 반격하세요.
- **벽꿍:** 생존자 평타에 맞은 상대가 밀려나다 벽에 부딪히면 큰 피해가 더 들어갑니다. **달리기 점프 발차기**로 벽 쪽으로 차 넣는 것이 기본 공격입니다.
- **두 번째 날아 차기:** 발차기 뒤 공중에서 한 번 더 클릭하면 한 번 더 찹니다. 머리에 맞히면 상대가 1.5초 동안 넘어집니다.
- **낙하:** 3층 높이(3층 우물, 무너진 곳, 옥상 길)에서 밀어 떨어뜨리면 약 45의 큰 피해가 들어갑니다.
- **판자:** 문간이나 좁은 틈에 있는 판자 옆에서 `Space`를 누르면 판자가 넘어갑니다. 감시자가 깔리면 큰 피해를 입고 2초 동안 기절합니다. 판자는 한 번만 쓸 수 있습니다.

### 감시자는 이렇게 이깁니다
- 평타 한 방이 크지만 느리고, 빗나가면 빈틈이 큽니다. **확실할 때만 휘두르세요.**
- 생존자가 막고 있으면 정면으로 치지 말고 **옆이나 뒤로 돌아가세요.** 뒤에서 치면 피해가 1.2배입니다.
- **창틀을 넘는 상대는 피해를 2배로 받습니다.** 창틀 앞에서 기다리는 것도 방법입니다.
- 달리기가 짧으니 스태미나를 아껴 두세요.

## 맵

**고딕 저택**입니다. 본관(3층), 서관, 동관이 안뜰을 둘러싸고 있고, 묘지와 판자 구역이 바깥에 있습니다.

| 볼거리 | 설명 |
|---|---|
| 창틀 | 넘어서 지름길로 갈 수 있습니다. 넘는 동안 맞으면 피해가 2배입니다 |
| 판자 (생존자만) | 문간·좁은 틈에 20개 있습니다. 내려서 감시자를 깔 수 있고, 한 번만 쓸 수 있습니다 |
| 순간이동 거울 | 맵 네 모서리에 있고 **대각선끼리** 이어집니다. 걸어 들어가면 0.8초 뒤 반대편 모서리로 나옵니다. 누구나 쓸 수 있고, 쓴 뒤 5초 동안은 다시 못 씁니다 |
| 사다리 | 동관과 서관에 하나씩 있습니다. 오르는 동안 스태미나가 줄고, 다 떨어지면 미끄러집니다 |
| 높은 곳 | 3층 우물, 무너진 곳, 옥상 길, 옥상 테라스에서 1층으로 떨어지면 큰 피해를 입습니다 |
| 본관 지붕 | **햇볕에 탑니다**(초당 4). 오래 서 있지 마세요. 공중에 떠 있으면 괜찮습니다 |

## 처음 하는 분을 위한 팁

1. **연습 모드부터** 해 보세요. 쿨타임이 없어서 스킬을 마음껏 써 볼 수 있습니다.
2. **생존자라면 왼쪽 클릭을 꾹 누르는 습관**을 들이세요. 감시자 평타를 막으면 반격 기회가 생깁니다.
3. 생존자의 진짜 피해는 **벽꿍과 낙하**에서 나옵니다. 상대를 벽이나 낭떠러지 쪽으로 몰아가세요.
4. 감시자는 **한 방이 크니 서두르지 마세요.** 빗나가면 그만큼 맞습니다.
5. **점프로 평타를 피할 수 있습니다.** 땅에서 휘두르는 평타는 높이 뛴 상대에게 닿지 않습니다.
6. 스태미나가 0이 되면 한동안 걷기만 할 수 있습니다. **노란 바를 보면서 달리세요.**
7. 쫓기거나 멀리 가야 할 때는 **모서리 거울**을 쓰면 반대편 모서리로 바로 갈 수 있습니다.
